# App Store screenshots

The upload-ready iPhone 6.5-inch screenshots are in `final/` at 1284 x 2778 pixels.

| File | Feature copy | Source |
| --- | --- | --- |
| `01-host-control.png` | Run the whole party from your pocket | Simulator Host screen, framed in shots.so |
| `02-upload-status.png` | See every upload at a glance | Simulator Photos screen, framed in shots.so |

The unedited shots.so exports are kept in `shots/`. Credential-safe simulator captures are kept in
`source/`.

`source/03-host-controls-safe.png` is a credential-safe derivative used for the marketing mockup. The live join QR section is intentionally obscured and must not be restored in public store artwork.
Raw Host and Invite captures containing a live join QR are ignored locally because the QR is a
bearer credential and this repository is public.
